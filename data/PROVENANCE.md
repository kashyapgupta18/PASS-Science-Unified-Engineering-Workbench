# Data Provenance Documentation

All bundled data files in this repository are self-created and synthetic. None are real CAD models or actual ANSYS solver exports.

## 1. `sample_unit_cube.stl`
- **Type**: ASCII Stereolithography (STL) surface mesh
- **Provenance**: Hand-authored geometric definition of a unit cube with side length 1.0.
- **Triangles**: 12 triangles (2 per face across 6 cube faces).
- **Units**: Unitless / metres (normalized 1.0 m cube).
- **Bounding Box**: X ∈ [0, 1], Y ∈ [0, 1], Z ∈ [0, 1].
- **Classification**: **Synthetic Demonstration Data**.

## 2. `sample_temperature_synthetic.csv`
- **Type**: Nodal temperature CSV
- **Schema**: `node_id,x_m,y_m,z_m,temperature_C`
- **Provenance**: Procedurally generated by Python script on a regular 6 × 6 × 6 Cartesian grid (216 nodes).
- **Grid Range**: x ∈ [0.0, 1.0], y ∈ [0.0, 1.0], z ∈ [0.0, 1.0] with step size 0.2 m.
- **Synthetic Field**: $T(x,y,z) = 20.0 + 80.0x + 30.0yz$ °C.
- **Min Temperature**: 20.0000 °C (at x=0, y=0, z=0).
- **Max Temperature**: 130.0000 °C (at x=1, y=1, z=1).
- **Mean Temperature**: 67.5000 °C.
- **Classification**: **Synthetic Demonstration Data** — explicitly NOT an ANSYS export.

## 3. Test Failure Datasets
- `test_malformed.stl`: Contains corrupt vertex tokens (`vertex 1 2 abc`) to test parser line-specific error handling.
- `test_empty.stl`: Contains zero triangles to verify empty-geometry diagnostics.
- `test_missing_column.csv`: Omits the `z_m` column to verify strict schema validation.
- `test_nan_values.csv`: Contains `NaN` and `Inf` tokens to verify floating-point sanitization.
- `test_duplicate_ids.csv`: Contains non-unique `node_id` values to verify topological ID checks.
- `test_valid_small.csv`: Minimal 5-node test dataset for unit testing.
