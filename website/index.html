Desktop Workbench Architecture

Separation of concerns: UI-independent C++17 core (wb_core) drives both the Win32/Direct3D 11 desktop GUI, standalone CLI tools, and automated unit test runners.

1. Geometry View

Interactive 3D viewport with rotation, pan, zoom, and fit-to-view. ASCII STL parser detects non-finite coordinates, degenerate triangles, and computes strict spatial bounding boxes.

2. Thermal FEA

Steady-state 1D thermal finite element solver. Exact Dirichlet boundary condition enforcement, linear element midpoint interpolation, and observed second-order O(h²) convergence.

3. Multicore Scaling

Bounded worker thread pool (1, 2, 4 workers) with lock-free atomic chunk assignment. Strict serial/parallel numerical agreement verified within 1e-8 °C tolerance.

4. Embedded Systems

Modular host-connected topology for STM32F407 MCU, Artix-7 FPGA, and SEGGER J-Link JTAG probe. Injected timeout fault simulation and 3-attempt bounded retry recovery.

Embedded Hardware Subsystems

Modular bus integration design and robust simulated device adapters with fault recovery.

Subsystem Topology

A single Windows 11 host communicates through a powered USB 2.0 hub (5.0V VBUS, 500mA per port) with three discrete devices:

  • STM32F407 MCU: ARM Cortex-M4, 168 MHz, 3.3V IO, USB-UART at 115200 8N1.
  • Xilinx Artix-7 FPGA: 1.0V VCCINT core, 3.3V Bank 34 IO, telemetry reporting fabric utilization and clock health.
  • SEGGER J-Link JTAG Probe: Specialized debug interface dynamically monitoring target VTref (1.65–3.6V). Drives TCK/TMS/TDI; reads TDO.
